# Kranarna som byggde Göteborg

Ett responsivt scrollytelling-utkast om Göteborgs varvsindustri. Berättelsen följer
samma älvstrand från 1840-talet, genom storvarvens höjdpunkt och kris, till dagens
bevarade kranar och industrimiljöer.

## Utveckling

```bash
pnpm install
pnpm dev
```

Bygg en statisk version med `pnpm build`.

Historiska bilder ligger lokalt i `public/images`. Källor och licenser redovisas i
berättelsens avslutande källsektion.

Typsnitten är självhostade i `public/fonts`. Tillhörande OFL-licenser ligger i samma
mapp.
